# MaaUma 资料与规划工具箱

本工具随 MaaUma 0.4.40 提供。在面板的“种马规划”中点击“资料工具箱”打开；“带当前账号与目标到工具箱”会主动带入本次选中的资料。育成配置“角色与配卡”中也可带入目标、支援卡声明和技能清单。

工具箱只监听本机 `127.0.0.1:18765`，由同目录的 `runtime/pythonw.exe` 启动。请保持 `knowledge-tools` 与 MaaUma 主程序的目录关系，不必另外安装 Python。若未找到 Node，网页的赛道计算会使用随包浏览器 Worker；其他查询和系谱功能不依赖 Node。

## 可用功能

- 查询技能、角色、衣装、三服对应名和支援卡技能来源。
- 规划两亲四祖系谱，比较基本相性、实际共同胜场和改泥等红因子缺星；可导入已有、可借、待培养的种马资料。
- 按启发等级、切者、上下位链和已学技能报价 SP；费用缺项保留未知或区间。
- 按赛道、跑法、五维和技能计算参考收益；国服与繁中服尚未逐服校准，结果不等于真实马群胜率。
- 打字查询资料或调用本地计算，例如“泥地E到A需要几星”。这部分是本地工具路由，不会凭聊天模型心算数值。

## 和面板联动

带入资料后，可在工具箱修改系谱、目标、卡组声明或技能清单，勾选要保存的内容并“保存草稿”；回面板点击“取回工具箱草稿”。取回只填写草稿，不会自动更换游戏卡组或开始育成。原策略版本、学习时间与折扣、资源预算及其他步骤保留。

工具箱改出的卡组属于推荐参考；在面板核对游戏中实际卡组后，才可主动用作本次填写。固定祖辈、实际胜场、已拥有与待培养状态分别保存。没有录入的持有状态不会自动变成“已有”。

只使用用户明确导入或从面板主动带入的资料。独立本地存储位于当前用户本地应用数据目录 `MaaUmaToolbox/local-store`；不自动扫描或读取其他安装的账号库。显式“载入演示马库”使用随包合成例子，不是真实账号资料。QQ 适配器仅提供离线调用源码，没有登录或发送群消息。

完整 AI 团队规划使用 MaaUma 面板中用户配置的 AI 接口；工具箱本地计算与草稿交换不依赖该接口。当前发布检查不宣称真实账号与远程 AI 的完整方案已验收。
