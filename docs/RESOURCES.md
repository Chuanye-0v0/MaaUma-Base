# 运行资源与访问权限

本仓库开放普通基础客户端的代码。代码许可证和运行输入、远程服务权限分别管理。

## 独立运行输入

[required-inputs.json](../resources/required-inputs.json) 列出普通版所用外部文件的相对位置，包括识别模板、图像、技能/因子/种马规划目录等。清单中的名字是接口约定，不是文件已经随仓库交付的声明。

游戏识别图、人物头像、游戏数据库及其派生目录、OCR 权重、字体/音频和预编译运行环境，不因本仓库 GPL 声明自动获得许可。使用者应为自己提供的输入保留来源及适用许可；没有明确再分发依据的输入不应提交到本仓库。自行构建、替换或生成的输入也应记录其来源。

源码导出保留应用自定义配置和示例接口，排除了个人配置、账号状态、授权回执、运行账本和历史日志。运行时新产生的这些文件仍应留在本机，不加入提交。

GUI 使用自有代码/几何标志和系统字体。依赖包自行携带的资源遵循相应依赖的许可，不由本项目重新授权。

## 客户端更新和激活

普通功能与基础更新的客户端代码在公开范围内，版本更新和测试版激活界面保留。激活界面源代码可见，不表示具有某个远程服务账号或私有扩展的权限。

个人码、个人授权数据和服务端密钥不随本仓库提供。私有 Pacer 引擎、育成/刷切组件及服务端实现属于独立范围。客户端可以按用户既有授权访问相应接口；软件源码的 GPL 权利和远程服务/独立组件的访问权限应分别理解。

本仓库不以原服务的授权作为编译普通客户端的条件。修改、构建和分发本仓库代码时仍按代码与各第三方组件的许可证执行。
